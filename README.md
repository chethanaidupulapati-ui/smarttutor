# AI Smart Tutor
AI Smart Tutor is an AI-powered learning platform built using Python and Streamlit.
It provides a modern and interactive dashboard for students.
The platform supports personalized learning and educational activities.
It includes student performance tracking and learning analytics.
Users can explore lessons and take interactive quizzes.
The dashboard displays lessons, average scores, quizzes, and students.
The application uses a dark-themed and responsive user interface.
Custom HTML and CSS are used for styling and animations.
To run the project, install Streamlit using `pip install streamlit`.
Run the application with `streamlit run smarttutor.py`.
